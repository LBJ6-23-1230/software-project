## 追溯与限制

各功能证据保留 `Fxx → 需求 → 设计 → 实现文件/真实提交 → 测试命令及输出 → 演示截图`。共享集成用例需说明谁实际编写、运行和审核。建议在 `docs/verification.md` 或实验报告记录环境、日期、用例编号、结果与问题；文件存在和实际通过之前，不写“已通过”。性能数据需记录机器、数据量、次数与耗时，本表不预填实测性能。

校园绑定、消息、匹配、备份分别为演示绑定、REST 刷新/轮询、可解释规则、手动备份恢复。真实学校 SSO、WebSocket、大模型匹配、定时备份为扩展，不作为已完成能力。
