## 审查处理与已知限制

- 保留 [DSH 第一轮审查](../reports/code-review-2026-10-24.md)。其中认领/争议等待续项仍是待续项。当前会话尝试追加独立审查时因模型额度失败，未获得新的独立审查结论。
- DSH 所述注册判重竞态：当前单 Node 进程、同步 SQLite 与同步 scrypt 的处理函数没有异步让出点，报告描述的两个请求同时越过 SELECT 并未得到复现。多进程共享库属于后续部署评审范围，不能把报告推断写成已确认漏洞。
- 登录未实现速率限制、安全头与生产会话机制仍待加固；演示账号及密码公开，仅供本机课程演示。不要直接用于真实校园生产环境。
- 演示绑定可由本人设置，不代表学校认证；消息采用 REST 轮询；匹配为规则；备份手动执行。争议只记录调解结果，不绕过认领状态机强制改终态。
- 已批准但未完成的认领暂不支持再次撤销/改派；失败时显示错误反馈。后续可在状态机与测试中共同扩展，不能直接改库。
- 此版本为 AI 辅助搭建与集成，不是四位同学各自独立完成或教师已验收的证明。
