# 前端视觉优化记录 · 2026-10-24

范围：F04–F06 发布浏览、F07–F09 认领页面与共享视觉层；全局 CSS 同时影响 F01–F03、F10–F12 的既有控件。保持原布局风格及业务行为，不涉及需求、API 或状态机变更。

| 项目 | 修改与原因 |
| --- | --- |
| 1. 颜色 | 全部 CSS 字面色值收进 `:root`，按正文、辅助、面板、主色、危险、寻物橙、边框、遮罩及阴影归并；保留指定六种基准色。增加 `prefers-color-scheme: dark` 变量覆盖与原生控件配色。文字最低 12px，根字号及主要正文 16px；标签使用不透明底色，避免图片影响对比度。 |
| 2. 间距 | margin、padding、gap 归到 8px 倍数，常用 8/16/24/32 使用变量；卡片内容统一 16px、主要面板 24px，移动端主要面板 16px。边框、图标、装饰定位不按间距强行取整。 |
| 3. 交互 | 全局 `:focus-visible` 环，列表/页签焦点环向内避免裁切；按钮、可点卡片统一悬停上移 2px 与阴影、按下复位，触屏不依赖悬停。认领中的拒绝/撤销及确认按钮用红色系，保留明确操作文字和确认说明，不只依赖颜色；保留减少动态效果支持。 |
| 4. 表单 | 原生 `:user-invalid` 和已有/未来 `aria-invalid` 提供红边、浅红底和标签反馈；说明文字与字段左沿对齐，错误框加明显左边框。禁用控件改为清晰的中性色，已读取页面的按钮用现有 busy 值补 `aria-busy` 与加载标记，不改变禁用条件。 |
| 5. 移动端 | 中间布局断点由 1000 调到 1080px，详情/表单/认领折为单列；760px 保留抽屉，关闭时 visibility 隐藏以退出键盘焦点顺序，打开时限制背景滚动，侧栏自身可滚动。卡片按最小 240px 自适应，狭屏退为单列；长标题、元信息、操作区允许换行；按钮/表单控件目标至少 40px。 |

**实现文件**：`src/styles.css`；`src/App.tsx`、`src/modules/items/Explore.tsx`、`src/modules/claims/Claims.tsx` 仅 className / aria 属性。`src/components/ui.tsx` 已阅读，未修改。

**实际核验**：使用本地已有 TypeScript 解析器、PostCSS 解析器进行静态检查，并与编辑前内存快照比较页面源码（排除 className / aria 属性后相同）。计算 sRGB 相对亮度：正文/辅助/主色/橙/红文字与四种基础底色组合的最低对比度，浅色为 5.06:1、暗色为 6.80:1，均高于正文 AA 的 4.5:1。这只是色值计算，不代表所有浏览器渲染状态已通过无障碍验收。

**未修改与依赖**：未改接口、state、路由、共享类型、后端、依赖；未执行测试、构建、dev server、git、安装、部署或删除。按本轮限定未通读仓库或其他模块页面。错误目前为请求级字符串，无法可靠判定具体错误字段；没有把网络/权限错误冒充字段错误，也未增加错误 ID/字段描述关联或验证逻辑。原生校验说明由浏览器提供；逐字段持久说明需后续授权。抽屉打开后尚无焦点圈定、Esc 关闭、焦点恢复逻辑，保留为交互缺口；业务逻辑未专项审查。

**浏览器人工确认**：在浅/暗色及 320/375/760/761/1080/1081px、200% 缩放下检查广场、认领、弹窗和受全局样式影响的其他页面；确认长文本不横向溢出、触控区域及焦点环完整。用 Tab 检查关闭抽屉不可聚焦、打开后关闭按钮可达，点击遮罩关闭、侧栏滚动和背景锁滚正常。检查表单原生校验红边与提示、请求错误、禁用与加载区别、危险确认文字、减少动态效果设置。以上浏览器核验均未执行，不能声称抽屉完整行为或全站 WCAG AA 已通过。
